# 考研 S.O.P. 作战台

一个单文件网页应用，用来管理考研冲刺期的每日执行与进度。

## 功能

- **今日**：倒计时 / 今天 3 件勾选 / 看板（自动算保命班滞后天数）
- **看板**：保命班 vs 课程折线、英语客观分柱状、四科进度、五道闸门倒计时
- **历史**：打卡月历 + 及格日统计
- **周复盘**：本周自动汇总 + 下周唯一目标 + 闸门判定
- **计划**：爬坡表 / 三种时间块 / 五道闸门 / SOP 摘要

## 使用

浏览器直接打开 `index.html`。数据存在浏览器 localStorage，**不上传任何服务器**。

建议每周日通过 `#set` 页面导出一次 JSON 备份。

## 部署到 GitHub Pages

1. 设置 → Pages → Source: Deploy from a branch → `main` / `/ (root)`
2. 访问 `https://<你的用户名>.github.io/sop/`
3. iPad Safari 打开后「添加到主屏幕」

## 说明

纯 HTML/CSS/JS 单文件，零依赖、零构建。
