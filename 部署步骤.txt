考研 S.O.P. 作战台 —— 说明
========================================================

【它是什么】
  一个单文件网页应用（index.html）：每天打卡、看进度、看计划。
  数据只存在你设备的浏览器里（localStorage），不上传任何服务器。
  全部点选，不需要打字。

【三个页签】
  今日  ：
    · 「今天要做」：底线 3 件（做完＝及格）+ 拉满 4 件（状态好全上）
    · 「保命班」：点 − / ＋ 记一天；课程 Day 自动按天推进，滞后天数自动算
    · 「概率 / 信号」：点到今天学到的那一章
    · 「英语今天写了什么」：可多选（阅读1-2 / 阅读3-4 / 新题型 / 完型 / 翻译 / 作文 / 整卷）
    · 「今天到此为止」：点一下归档，顶部出现绿色横幅，按钮变"已归档"，再点可取消

  回顾  ：保命班 vs 课程折线 / 打卡月历 / 累计统计 / 周复盘 + 下周唯一目标
  计划  ：爬坡表（自动高亮"现在"）/ 闸门倒计时 / 时间块与 SOP 参考 / 备份与外观


============================================================
一、先在电脑上试用
============================================================
  最稳的方式（能验证"刷新不丢"）：
     在本文件夹打开 PowerShell，执行：
         python -m http.server 8123
     浏览器访问 http://127.0.0.1:8123/

  也可以直接双击 index.html，但 file:// 下部分浏览器不保存数据。


============================================================
二、放到 iPad 上（GitHub Pages，已配置好）
============================================================
  网址：https://adiduhui.github.io/sop/

  1. iPad 用 Safari 打开上面的网址
  2. 点「分享」→ 往下滑 → 「添加到主屏幕」
  3. 以后点桌面图标 = 全屏应用


============================================================
三、以后怎么更新这个网站
============================================================
  改完 index.html 后，在本文件夹的 PowerShell 里执行：

      git add -A
      git commit -m "update"
      git push

  等 1~2 分钟，刷新网址即可看到新版本。


============================================================
四、数据备份（唯一的风险点）
============================================================
  数据只在那台设备的浏览器里。清缓存、换浏览器、换设备都会丢。

  导出：计划 → 参考 → 备份与外观 → 「导出备份」
        得到 sop-backup-日期.json → 存到网盘 / 夸克 / 微信收藏
  恢复：同上 → 「导入备份」→ 选那个 json 文件

  【建议】每周日复盘时顺手导出一次。
  【注意】旧版（v1）数据会自动迁移到新版，不会丢。


============================================================
五、每天怎么用（30 秒）
============================================================
  早上：打开 → 看一眼倒计时 → 干活

  做一件就点一下：
    □ 在「今天要做」里勾
    □ 保命班点 ＋
    □ 概率 / 信号 chip 点一下
    □ 英语 chip 点一下
    □ 最后点「今天到此为止」

  周日：进「回顾」看本周及格日 → 点一个"下周唯一目标" → 导出备份


============================================================
六、常见问题
============================================================
  问：白屏？
  答：确认文件名还是 index.html，不要改。

  问：数据能同步到另一台设备吗？
  答：不能。用"导出 → 导入"手动搬。

  问：概率/信号 chip 点错了？
  答：再点同一个就取消，或点另一个替换。

  问：保命班点错了？
  答：按旁边的 − 退回去。

  问：想改计划内容？
  答：改 index.html 里「计划」页那段 HTML 即可，不影响打卡数据。
