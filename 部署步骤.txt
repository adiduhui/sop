考研 S.O.P. 作战台 —— 部署与使用说明
========================================================

【它是什么】
  一个单文件网页应用（index.html），用来每天打卡 + 看进度。
  数据只存在你自己的浏览器里（localStorage），不上传任何服务器。

【核心功能】
  今日    ：倒计时 / 今天3件勾选 / 看板输入（保命班Day、课程Day → 自动算滞后）
  看板    ：保命班 vs 课程 折线 / 英语客观分柱状 / 四科进度条 / 五道闸门倒计时
  历史    ：打卡月历（绿=3件全勾，浅橙=有记录没勾满）+ 统计
  周复盘  ：本周自动汇总 + 下周唯一目标 + 自动闸门判定
  计划    ：爬坡表 / 三种时间块 / 五道闸门 / SOP 摘要（折叠卡片）
  设置    ：导出备份 / 导入备份 / 深浅色 / 清空
        （设置页从底部导航以外的入口进入：地址栏加 #set）


============================================================
一、先在电脑上试用（1 分钟）
============================================================
  1. 双击 index.html，用 Edge 或 Chrome 打开
  2. 勾几件、填几个数、刷新页面 → 数据应该还在
  3. 点底部「计划」页看看内容是否完整

  注意：直接用 file:// 打开时，localStorage 在部分浏览器里可能不保存。
        要验证"刷新不丢"，最好用下面的本地服务方式：

      在 sop 文件夹里打开 PowerShell，执行：
          python -m http.server 8123
      然后浏览器访问 http://127.0.0.1:8123/


============================================================
二、放到 iPad 上（推荐：GitHub Pages，约 5 分钟一次性配置）
============================================================
  【第 1 步】注册 / 登录 GitHub
      https://github.com

  【第 2 步】新建仓库
      右上角 + → New repository
      Repository name 填：sop
      选 Public（必须公开，免费版 Pages 只支持公开仓库）
      点 Create repository

  【第 3 步】上传文件
      仓库页面点 "uploading an existing file"
      把 index.html 拖进去
      Commit changes

  【第 4 步】开启 Pages
      仓库顶部 Settings → 左侧 Pages
      Source 选 "Deploy from a branch"
      Branch 选 main，文件夹选 / (root)
      点 Save

  【第 5 步】等 1–2 分钟，记下网址
      网址形如：https://你的用户名.github.io/sop/
      （刷新仓库的 Actions 页面可以看到部署状态）

  【第 6 步】iPad 加到桌面
      iPad 用 Safari 打开上面的网址
      点分享按钮 → 「添加到主屏幕」
      之后点桌面图标 = 全屏应用，跟 App 一样


============================================================
三、备选方案（不想用 GitHub）
============================================================
  方案 A：Netlify Drop
      https://app.netlify.com/drop
      把整个 sop 文件夹拖进去 → 立刻得到一个网址

  方案 B：不联网
      把 index.html 存到 iPad 的「文件」App
      用 Documents by Readdle 这类能跑 JS 的 App 打开
      缺点：数据沙盒独立，务必每周导出备份


============================================================
四、数据备份（非常重要）
============================================================
  数据只在你那台设备的浏览器里。清缓存、换浏览器、换设备都会丢。

  操作：地址栏加 #set 进入设置页 → 点「导出备份」
       得到 sop-backup-日期.json → 存到网盘 / 微信收藏

  恢复：设置页 → 「导入备份」 → 选那个 json 文件

  【建议】每周日复盘时顺手导出一次。


============================================================
五、每天怎么用（30 秒）
============================================================
  早上：
    打开 → 看倒计时 → 写下今天 3 件（心里定好就行，页面上是固定3类）

  白天：
    勾一件就点一下；课堂时长随手填

  晚上：
    填保命班 Day / 课程 Day（页面自动告诉你落后几天）
    填备注"今天卡在哪"
    点「今天到此为止」

  周日：
    进「周复盘」→ 看本周及格日 → 写下周唯一目标 → 保存
    再进 #set → 导出备份


============================================================
六、常见问题
============================================================
  问：打开是白屏？
  答：检查是不是把 index.html 单独移动了位置；它是一个自包含文件，
      放在哪都能开，但不要改文件名。

  问：数据能同步到另一台设备吗？
  答：不能。用"导出 → 导入"手动搬。

  问：进度条为什么不动？
  答：四科进度读的是"最近一次有值的记录"。你在看板里填了
      概率进度/信号进度/英语客观/政治剩题，进度条才会动。

  问：想改计划内容？
  答：改 index.html 里「计划」页那段 HTML 即可，不影响打卡数据。
      但按 SOP 的锁定规则：结构定了就别反复改。
